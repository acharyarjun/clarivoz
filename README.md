# Clarivoz

Bilingual English and Spanish diction and leadership speaking coach. Ten minutes a day: pen-in-mouth drills, tongue twisters, and leadership scenarios.

The web app is at [acharyarjun.github.io/clarivoz](https://acharyarjun.github.io/clarivoz/).
